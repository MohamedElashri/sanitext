About SaniText

Inspect Unicode text and clean up lookalike, invisible, or unsupported characters in your browser.

Using the tool

Detect only
Inspect flagged characters and their Unicode code points while keeping your text as it is.
Sanitize text
Clean up characters outside the allowed set. SaniText keeps printable ASCII, tabs, and line breaks by default.
Paste, open, and copy
Paste from the clipboard or open a local file. When the output is ready, copy it back to your clipboard.

Settings

Allow emoji
Keep common single-code-point emoji during sanitization.
Interactive mode
Choose whether to keep, remove, or replace each unique flagged character.
Verbose mode
Show detection results when sanitizing and include occurrence counts and decimal code points.

How cleanup works

SaniText checks each character against the allowed set. In automatic mode, it processes flagged characters in this order.

  1. Look for a visually similar ASCII character, such as replacing Cyrillic Н with Latin H.
  2. Try Unicode compatibility normalization and keep the result if it uses allowed characters.
  3. Remove the character if no allowed replacement was found.

When to use SaniText

  • Inspect text for lookalike letters and invisible characters.
  • Prepare data for systems that accept only ASCII.
  • Check text before sending it to software with limited character support.
  • Standardize text that uses several Unicode forms for similar characters.
