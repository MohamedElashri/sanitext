Privacy policy

Data processing

All text processing in SaniText is performed entirely in your browser. We do not collect, store, or transmit any of your input data. The text you enter remains on your device and is processed locally.

Hosting

SaniText is hosted on GitHub Pages, a static site hosting service provided by GitHub Inc. The website is served directly from GitHub's servers as static content. GitHub may collect basic technical information as part of its standard hosting service, such as IP addresses and access logs. See GitHub's Privacy Statement for more information.

Contact

For questions about this privacy policy, contact us through the GitHub repository.
