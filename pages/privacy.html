Privacy Policy

SaniText is client based only. This privacy policy explains data is handled:

Data Processing

All text processing in SaniText is performed entirely in your browser. We do not collect, store, or transmit any of your input data. The text you enter remains on your device and is processed locally.

Hosting

SaniText is hosted on GitHub Pages, a static site hosting service provided by GitHub Inc. The website is served directly from GitHub's servers as static content. GitHub may collect basic technical information as part of their standard hosting service, such as IP addresses and access logs. For more information about GitHub's privacy practices, please visit GitHub's Privacy Statement.

Contact

If you have any questions about this privacy policy, you can reach through the GitHub repository.
